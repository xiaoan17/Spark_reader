# Spark 引读 · 内测邀请文案

> **每一次阅读,都是一颗火花。**

跟大家分享一个我们刚做出来的东西 🎉

我们做了一个 AI 阅读器,叫 **Spark 引读**,现在出了测试版,想请你来当第一批用户。

读书的时候,你一定遇到过这种时刻:某一段话似懂非懂,想搞明白,又懒得翻遍全书找上下文。

Spark 引读做的就是这件事:**导入 PDF,框选你卡住的那段话**,AI 会围绕这段话检索全书证据,给你一份解读,而且每一条都能点回原文出处,有据可查,不是凭空编的。

我们希望,每一次框选、每一次追问,都能点亮一颗火花——火花攒多了,一本书就读透了。

## 下载

📦 **下载地址**:<https://github.com/xiaoan17/Spark_reader/releases/latest>

下载最新的 `Spark_x.x.x_aarch64.dmg`,双击打开,把 **Spark** 拖进「应用程序」就装好了。

## 几个提前说明

- 目前仅支持 **Apple Silicon(M 系列)Mac**,系统要求 macOS 11+。
- 内测包还没做苹果公证,首次打开请 **右键 Spark → 选择「打开」**;如果仍被拦截,在终端执行:

  ```bash
  xattr -cr /Applications/Spark.app
  ```

- 需要自己配两个 API,启动后在应用内「设置」里填:
  - **MinerU Token**(PDF 解析):<https://mineru.net/apiManage/token>
  - **一个 LLM Key**(AI 解读),用 DeepSeek 就行:<https://platform.deepseek.com/api_keys>
