# 对照翻译对齐方案

## 目标

`转换稿` 与 `对照翻译` 必须共享同一套原文版式。Spark 标记、高亮、引用回跳和视图切换都以原文锚点为准，译文只作为挂载在原文块旁边的辅助内容。

## 约束

- 对照翻译使用稳定的左右均分分屏：左侧英文原文、右侧中文译文，共享同一个页容器和滚动节奏。
- 禁止把译文做成悬浮 rail、overlay 或脱离文档流的绝对定位面板；译文必须在右侧固定 pane 中自然排版。
- 译文不是卡片列表：左右两侧都使用阅读正文样式，常态下不显示灰底卡片或色条；只有 hover、当前选择、Spark 命中时才做轻量块级提示。
- 对齐基准是块 ID：翻译协议中的 `[[B001]]`、`[[B002]]` 映射到同页原文块。
- 视觉对齐基准同样是块 ID：同一个 `B###` 的英文块和中文块必须占用同一 grid row，允许行高由较长一侧撑开。
- 中文侧选择是块级锚点：用户在译文 pane 中框选时，Spark 使用对应英文原文块作为 selection text 和 anchor，避免把译文当作最终证据。

## 取舍

短期不做词级中英对齐。没有模型返回的词级 alignment 时，中文短语无法可靠映射到英文短语；先落到块级原文锚点，保证 Spark、RAG 和持久化引用稳定。
