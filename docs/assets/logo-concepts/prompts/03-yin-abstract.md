Concept direction: abstract Chinese idea of "引" without relying on readable text.

Create a square app-icon logo mark inspired by the Chinese idea of "引": guiding, drawing out, leading from one passage into deeper context. Do not write the readable character. Instead, design an abstract glyph made from a page edge, a selected text bracket, and a fine guiding line ending in a small anchor point. The form should feel slightly calligraphic but still clean, geometric, and suitable for a modern desktop app.

Composition:
- Abstract symbol only, no actual Chinese text.
- Warm ivory base, ink charcoal main glyph, muted teal guide line.
- One tiny warm spark near the beginning of the guide line.
- Calm, scholarly, premium.
