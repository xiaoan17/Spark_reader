Concept direction: Spark / S app-icon glyph.

Create a square app-icon logo mark with an abstract "S" silhouette formed from a selected text frame and a folded page path. The S should be implied by geometry, not written as plain typography. It should suggest a reader moving from a selected passage into deeper evidence and back to the page. Use muted teal as the main accent, ink charcoal for structural strokes, and a single tiny golden spark where the S crosses the selected passage.

Composition:
- Premium macOS-style rounded-square icon on warm ivory.
- Strong centered S-like mark, simple and memorable.
- No wordmark, no extra letters, no readable text.
- Restraint over decoration.
